# vdm-02456
Variational diffusion models provide new insight into likelihood-based generative modeling with diffusion models. They are considered as a way of connecting diffusion models and VAEs wherein the forward diffusion process is interpreted as part of the variational inference procedure.The model learns to approximate the true data distribution using a variational lower bound (VLB) and each diffusion step compresses data while the denoising network parameterises the posterior distributions [1].
[1] T. Kingma, P. Dhariwal, and A. Ho, “Variational Diffusion Models,” arXiv preprint arXiv:2107.00630, 2021. [Online]. Available: https://arxiv.org/pdf/2107.00630
